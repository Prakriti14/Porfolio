# Prakriti portfolio

React + TypeScript + Vite. All your content lives in `src/data.ts`.

## Run locally
```
npm install
npm run dev
```

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. Go to vercel.com/new, import the repo.
3. Vercel detects Vite automatically (build: `npm run build`, output: `dist`). Click Deploy.

Or from the terminal: `npm i -g vercel && vercel --prod`.
